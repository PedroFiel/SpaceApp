# 🚀 Space App

Uma aplicação web moderna desenvolvida com React e Vite para explorar e visualizar imagens do espaço.

## 📋 Sobre o Projeto

O Space App é uma aplicação web que permite aos usuários visualizar e explorar imagens relacionadas ao espaço. Construído com tecnologias modernas, o projeto oferece uma interface intuitiva e responsiva para a navegação de conteúdo espacial.

## 🛠️ Tecnologias Utilizadas

- **React** (v18.3.1) - Biblioteca JavaScript para construção de interfaces
- **Vite** (v5.4.1) - Build tool e dev server
- **Styled Components** (v6.1.12) - Biblioteca para estilização com CSS-in-JS
- **ESLint** (v9.9.0) - Ferramenta de linting para JavaScript/React

## 🚀 Como Executar

1. **Clone o repositório**
   ```bash
   git clone https://github.com/PedroFiel/SpaceApp.git
   cd SpaceApp
   ```

2. **Instale as dependências**
   ```bash
   npm install
   ```

3. **Execute o projeto em modo de desenvolvimento**
   ```bash
   npm run dev
   ```

4. **Para build de produção**
   ```bash
   npm run build
   ```

## 📁 Estrutura do Projeto

```
SpaceApp/
├── src/
│   ├── components/     # Componentes React reutilizáveis
│   ├── assets/        # Recursos estáticos (imagens, etc.)

```

## 🔧 Scripts Disponíveis

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Gera build de produção
- `npm run preview` - Visualiza a build de produção localmente
- `npm run lint` - Executa o linting do código
